---
title: Device Software
---

This section covers the code that runs on a Neuron device. It explains how
kernels lay out data in on-chip memory, which instructions they can use, and
what the compiler puts in the device executable.

If you are writing kernels, this is your section. Start with
[NKI](/neuron-glossary/device-software/nki) and
[tiles](/neuron-glossary/device-software/tile).
